# 날씨알려줭(WeatherProject)
## 요약
>검색 엔진에 날씨를 알려주는 백그라운드 비디오 출력 프로젝트

### 제작 이유
해당 프로젝트는 주로 실내에서 작업하는 분들이
점심시간이나 시간감각을 잃어 버렸을때 검색할때 마다 
날씨를 알 수 있도록 도와주는 페이지입니다.

## 소개
- 카카오 Open API를 이용한 검색 서비스
- 기상청 Open API를 이용한 날씨 확인 서비스
- 검색 시 연관성이 높은 순서 10개를 조회
- 현재 날씨를 반영하여 백그라운드 비디오 변경

작업 기간
- 2024.9.13 ~9.20 (1주)
개인 프로젝트

## 느낀점
- Open API의 기능을 새롭게 느껴서 좋았지만 처음 다루어 보는 내용이 많아 API의 사용에
- 너무 치우쳐 져 있는것 같습니다. 다른 프로젝트 시 API활용하게되면 다른 기능구현도 더욱 노력해야겠습니다.
- 미완성된 아이콘 기능들도 추가 할 수 있다면 추가 할 예정입니다.
- API 관리 방법이 있다고하여 보안에 더 철저할수 있도록 할 예정입니다.
